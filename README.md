# GRYNA® — Collection 001

Ready-to-upload static storefront with 25 concept garment images.

## Deploy
Upload **the contents of this directory**, not the enclosing folder, to the root of the `main` branch of `GrunaDan/G-R-U-N-A-`. Keep `index.html` at repository root and all 26 `.webp` files inside `assets/`.

Then go to GitHub → repository Settings → Pages → Source: Deploy from a branch → `main` → `/(root)` → Save.

Site URL once deployed: https://grunadan.github.io/G-R-U-N-A-/

## Notes
This is a pre-launch visual catalog. Images are design concepts, not verified manufactured products. Checkout and payments are not implemented. No third-party image hosting required. Google Fonts is optional; fallback fonts work offline.
